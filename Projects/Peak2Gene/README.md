# Peak2Gene

This project focuses on mapping genomic peaks to genes and comparing 
different peak-to-gene assignment methods on a single dataset.

---

## Objectives
- Map peaks to their closest genes using multiple methods
- Compare and evaluate the results of different approaches
- Generate gene-level summaries and visualizations
- Prepare data for downstream analysis or further studies

---

## Folder Structure
```
Projects/Peak2Gene/
├── data/          # Datasets
├── notebooks/     # R Markdown notebooks for each method and comparison
├── src/           # Helper R scripts
```
